# 🏢 AI 친환경 건물 시뮬레이터

딥러닝 신경망이 건물의 에너지 사용량과 탄소 배출량을 **실시간으로 예측**하고,
날씨에 맞춰 **창문 · 커튼 · 태양광 패널 · 풍력 발전기 · 빗물 수력 발전 · 옥상 살수 · 조명 · 배터리 · 냉난방**을 스스로 조절하는 시뮬레이터입니다.
같은 날씨에서 **일반 건물(정해진 시간표대로 운영)**과 **AI 건물**을 나란히 놓고 비교합니다.

## 실행 방법

`index.html` 파일을 더블클릭하면 크롬·엣지 같은 웹 브라우저에서 열립니다. 따로 설치할 것은 없습니다.

1. 처음 몇 초 동안 AI가 과거 데이터로 학습합니다(화면에 진행률이 보임).
2. 학습이 끝나면 시간이 흐르면서 AI 건물이 움직이기 시작합니다.
3. 아래쪽에서 **계절(월), 날씨, 바람, 미세먼지, 기온, 속도**를 바꿔 가며 AI가 어떻게 반응하는지 관찰해 보세요.
   - 예: 7월 + 맑음 → 커튼과 창문 조절, 1월 밤 → 커튼을 쳐서 단열, 강풍 → 패널을 수평으로 눕힘
   - 폭우 → 빗물이 홈통을 따라 흐르며 수차가 돌고 탱크가 참 / 태풍 → 풍력 발전기가 브레이크로 멈춤
   - 미세먼지 나쁨 → 창문을 닫고 필터 환기 / 한여름 맑은 날 → 모아 둔 빗물을 옥상에 뿌려 지붕을 식힘

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 구성 |
| `css/style.css` | 디자인 |
| `js/environment.js` | 주변 환경: 태양 위치(천문 공식), 일사량, 서울 월평균 기온, 바람, 재실 인원, 전력 탄소계수 |
| `js/building.js` | 건물 에너지 물리 모델: 15분마다 열의 출입을 계산해 실내 온도와 전력 사용량을 구함 |
| `js/neural.js` | 라이브러리 없이 직접 구현한 딥러닝 신경망(다층 퍼셉트론, 역전파, Adam) |
| `js/ai.js` | AI 두뇌: 학습 데이터 생성 → 신경망 학습 → 15분마다 최적 조합 선택 |
| `js/render.js` | 건물·하늘·날씨 애니메이션 그리기 |
| `js/charts.js` | 그래프 그리기 |
| `js/main.js` | 전체 연결, 시간 진행, 화면 갱신 |

## AI는 어떻게 판단할까?

1. **과거 데이터 수집**: 여러 날씨·시간·조절 상태에서 건물이 쓴 에너지 기록 6,000개를 만듭니다.
2. **딥러닝 학습**: 신경망(입력 9개 → 은닉층 32·32·16 → 출력 2개)이
   "이런 상황에서 이렇게 조절하면 → 15분 동안 전력 몇 kWh, 실내 온도 몇 도"를 배웁니다.
   - 입력: 바깥 기온, 실내 기온, 창문 면 일사량, 수평 일사량, 풍속, 재실률, 쾌적 모드, 창문 열림, 커튼 내림
   - 처음 보는 시험 데이터 1,000개로 정확도를 확인합니다(결정계수 R² 약 0.99).
3. **실시간 최적 제어**: 15분마다 창문 4단계 × 커튼 5단계 = 20가지 조합을 신경망으로 미리 예측하고,
   `탄소 배출 + 불쾌감`이 가장 적은 조합을 고릅니다. (화면의 "AI가 검토한 20가지 조합" 표)
4. **규칙 기반 보조 장치**
   - 태양광 패널: 태양 위치를 계산해 각도 추적, 강풍이면 수평으로 눕히고 눈이 오면 세움
   - 조명: 자연광이 부족한 만큼만 켬(디밍), 사람이 없으면 끔
   - 배터리: 남는 태양광과 전력망이 깨끗한 낮 시간 전기를 저장했다가 탄소가 많은 저녁 피크에 사용
   - 냉난방: 사람이 있을 때 21~25°C, 없을 때 17~28°C(절전), 출근 2시간 전부터 미리 온도를 맞춤
   - 안전 규칙: 비·눈이 오면 창문 닫기, 미세먼지가 나쁘면(35㎍/㎥ 초과) 창문 닫기, 강풍이면 조금만 열기, 사람이 없으면 보안을 위해 조금만 열기

## 날씨·환경에 따라 작동하는 장치 (AI 건물에만 설치)

| 장치 | 환경 조건 | 작동 원리 |
|---|---|---|
| 💧 빗물 수력 발전 | 비·폭우 | 지붕(300m²)에 떨어진 빗물을 홈통으로 모아 18m 아래 탱크로 흘려보내며 수차를 돌림. 위치 에너지 = 질량 × 9.8 × 높이 |
| 🛢️ 빗물 탱크·재활용 | 비가 그친 뒤 | 10톤 탱크에 모은 빗물로 화장실 물을 대신해 수돗물 절약 |
| 🚿 옥상 살수 냉각 | 30°C 가까운 맑은 날 | 모아 둔 빗물을 지붕에 뿌려 물이 증발하며 열을 빼앗음 → 냉방 전기 절약 |
| 🌬️ 옥상 풍력 발전기 | 바람 | 발전량 = ½ × 공기 밀도 × 면적 × 풍속³. 3m/s부터 돌고, 20m/s 이상 태풍이면 고장 방지를 위해 정지 |
| 😷 미세먼지 대응 | 미세먼지 나쁨 | 창문 환기를 막고 필터 환기 장치 사용. 비가 오면 먼지가 씻겨 내려가고, 바람이 강하면 흩어짐 |

**알게 된 점(탐구 포인트)**: 빗물 수력 발전은 시간당 40mm가 쏟아지는 폭우에도 약 0.3~0.4kW밖에 안 됩니다.
물의 양에 비해 떨어지는 높이(18m)가 낮기 때문입니다. 실제 수력 발전소가 큰 댐을 쓰는 이유이기도 합니다.
그래서 빗물은 **발전보다 저장·재활용(수돗물 절약, 옥상 냉각)할 때 더 가치가 크다**는 결론을 얻을 수 있습니다.

## 일반 건물(비교 대상)

창문은 항상 닫혀 있고, 커튼은 30%로 고정, 근무 시간에는 조명 100%, 태양광 패널은 남쪽 30°로 고정,
냉난방은 타이머(5~21시)로만 운영합니다. 풍력 발전기·빗물 시스템·옥상 살수 장치는 없습니다.
그래서 비교 결과에는 "AI 운영 방식"의 효과와 "친환경 설비를 추가한" 효과가 함께 들어 있습니다.

## 한계(보고서에 쓰면 좋은 부분)

- 건물 열 계산은 단순화한 모델(RC 모델)이라 실제 건물과 수치가 다를 수 있습니다.
- 학습 데이터는 실제 측정값이 아니라 물리 모델로 만든 가상 데이터입니다.
  실제로는 건물에 센서를 설치해 모은 데이터로 학습해야 합니다.
- AI는 15분 앞만 보고 판단합니다. 더 발전시키려면 몇 시간 뒤까지 내다보는 예측(모델 예측 제어)이 필요합니다.
- 기후는 서울 평년값, 전력 탄소계수는 한국 평균(약 0.46 kg CO₂/kWh)을 바탕으로 한 근사값입니다.
